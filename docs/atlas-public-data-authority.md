# Atlas Public Data And Authority Surface

Atlas exposes a small public proof layer for crawlers, reviewers, and developer platforms. The goal is citation and verification, not automated backlink schemes.

- Symbol coverage dataset: https://atlas.freedomcore.io/datasets/atlas-symbol-coverage/

- Security proof page: https://atlas.freedomcore.io/pages/atlas-security.html

## Scope

These assets are public metadata and short evidence indexes only. They do not contain private customer data, paid research bodies, trading instructions, or brokerage execution.

## Search Policy

Atlas will not use paid links, automated comment drops, link exchanges, fake directories, or generated third-party link networks. Public authority should come from useful crawlable data, reproducible security evidence, and reachable documentation.

## Citation

When referencing Atlas public datasets, cite the dataset landing page rather than a transient homepage module:

```text
Atlas Public Data Catalog
https://atlas.freedomcore.io/datasets/
```
